# Routine App 1.0.1 — classic design APK

Android application ID: `com.nahid.steadyroutine`; Expo app version `1.0.1`; Android version code `2`.

This build includes the classic default appearance, Today/Schedule/Progress/Settings tabs, and Settings → Upgrade Premium → Coming soon. All previously implemented local tracking, notes, routine templates and backup/restore features are included.

## EAS configuration

The `preview` profile in `eas.json` creates an internal-distribution APK. `ROUTINE_OFFLINE_BUILD=1` removes Internet and network-state permissions through the existing app config. Android native sources are generated by Expo CNG in the cloud.

The app is linked to `@nahidestes/steady-routine`, project ID `5b211251-952e-4dc3-bf4b-3be6749a7587`. EAS uses local credentials from ignored `credentials.json`. The existing preview signing key is backed up at ignored `artifacts/signing/routine-preview.keystore`, outside generated Android sources. This retains the previous personal-testing signing identity; it does not create a production signing identity. Keep the keystore if you need to update existing installations without uninstalling.

Build command:

```powershell
npx eas-cli@latest build --platform android --profile preview
```

If the signing backup is absent, restore the same signing keystore and update the local `credentials.json` path before building; do not generate a replacement key for an existing installation. Never commit `credentials.json` or keystores. The optional local build script now names its output using the configured Expo version, preserving earlier versioned APKs.
